# Dev Horoscope

A playful daily horoscope for developers based on their "code sign" - because even coders need cosmic guidance.

## Concept

Developers pick their "sign" based on their primary role/stack:
- **The Frontend Mystic** (React, Vue, CSS wizards)
- **The Backend Sage** (API architects, database whisperers)
- **The DevOps Oracle** (CI/CD prophets, cloud navigators)
- **The Mobile Nomad** (iOS, Android, cross-platform travelers)
- **The Full-Stack Dreamer** (Jack of all trades, master of some)
- **The Security Guardian** (Protector of secrets, hunter of bugs)

Each gets a daily horoscope with:
- Today's cosmic vibe
- Lucky commit message
- Bug prediction
- Recommended beverage
- Auspicious coding hours

## Tech Stack

- Next.js 14
- Tailwind CSS
- TypeScript
- Deployed on Vercel

## Data

Horoscopes rotate daily from a curated collection of 30+ readings. Date-based rotation without needing a database.
